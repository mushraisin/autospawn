# AutoSpawn

Клієнтський мод для **Minecraft 1.21.4 (Fabric)**.

Якщо гравець із твого списку заходить на сервер або вже перебуває на ньому — мод сам виконує `/spawn`.

## Що вміє

- Власне меню зі списком ніків, бінд за замовчуванням `]` (змінюється в **Налаштування → Управління → AutoSpawn**).
- Команда налаштовується — можна поставити будь-яку замість `/spawn`.
- Два режими: «вхід + онлайн» (спрацьовує і якщо гравець уже на сервері, коли заходиш ти) та «лише вхід».
- Індикатори онлайну прямо в списку, скрол, кулдауни, повідомлення в чат.
- Команди `/autospawn add|remove|list|toggle|run|menu`.

## Як мод знаходить гравця

Перевірка йде з трьох незалежних джерел, тому ціль не губиться:

1. таблиця гравців сервера — і за ніком профілю, і за відображуваним ім'ям із префіксом ранга;
2. сутності гравців у завантаженому світі — працює, навіть коли сервер ховає tab-list;
3. системні повідомлення чату про вхід.

Перевірка виконується 5 разів на секунду, а після заходу на сервер діє «розігрів» у 12 секунд —
за цей час tab-list встигає прийти повністю, тож гравець, який уже був онлайн, точно не пропускається.
Якщо клієнт у момент спрацювання ще не може надіслати команду, вона лишається в черзі
й іде першим же тіком, коли з'єднання готове.

## Установка

1. Fabric Loader для 1.21.4 + [Fabric API](https://modrinth.com/mod/fabric-api).
2. Кинути `autospawn-1.0.0.jar` у `.minecraft/mods`.

## Збірка з початкового коду

Потрібен JDK 21.

```bash
./gradlew build
```

Готовий jar — у `build/libs/`.

## Налаштування

Файл `config/autospawn.json`:

| Поле | Опис | Типово |
|---|---|---|
| `enabled` | головний вимикач | `true` |
| `command` | команда без слеша | `spawn` |
| `players` | список ніків | `[]` |
| `pollIntervalTicks` | період перевірки в тіках | `4` |
| `warmupSeconds` | скільки секунд після заходу поява = «вже був тут» | `12` |
| `cooldownSeconds` | мінімум між будь-якими двома відправками | `3` |
| `perPlayerCooldownSeconds` | мінімум між спрацюваннями по одному гравцю | `20` |
| `resendCount` | скільки разів продублювати команду (1–3) | `1` |
| `announce` | писати про спрацювання в чат | `true` |
| `triggerOnlyOnJoin` | реагувати лише на вхід | `false` |
| `detectViaChat` | ловити вхід також із повідомлень чату | `true` |
| `chatJoinPatterns` | фрази, які означають «зайшов» | укр/англ/рос |
